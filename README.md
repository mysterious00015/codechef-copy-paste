## ◈ ABOUT THE PROJECT

**CodeChef Copy** is designed to improve the competitive programming experience.

Instead of manually selecting and copying sample inputs and outputs, simply use the extension to copy test cases with one click.

Built for programmers who value speed, simplicity, and productivity.

## 📥 INSTALLATION

### Chrome / Brave / Edge

1. Download this repository as a ZIP.
2. Extract the ZIP file.
3. Open your browser's extensions page.

| Browser | URL |
|:---|:---|
| Chrome | `chrome://extensions` |
| Edge | `edge://extensions` |
| Brave | `brave://extensions` |

4. Enable **Developer Mode**.
5. Click **Load Unpacked**.
6. Select the extracted extension folder.

## 🧑‍💻 HOW TO USE

1. Open [CodeChef](https://www.codechef.com).
2. Navigate to a programming problem.
3. Open the problem in a new tab using `Ctrl + Click`.
4. Use the CodeChef Copy extension.
5. Copy the sample test cases with one click.

**TIP:** Refresh the problem page if the extension does not work immediately.
